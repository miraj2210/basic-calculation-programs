# Simple Calculator Using JavaScript

## Description
This is a simple calculator created using HTML and JavaScript. It takes two numbers and an operator from the user and performs a basic arithmetic operation.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Displays an error for invalid operators

## Technologies Used
- HTML
- JavaScript

## How It Works
1. The user enters the first number.
2. The user enters the second number.
3. The user selects an operator (+, -, *, /).
4. The calculator performs the operation using a `switch` statement.
5. The result is displayed on the webpage.

## How to Run
1. Download or copy the HTML code.
2. Save the file as `index.html`.
3. Open the file in any web browser.
4. Enter two numbers and an operator.
5. View the result on the webpage.

## Example Output

```text
First Number: 10
Second Number: 5
Operator: +
Result: 15
```

## JavaScript Concepts Used
- `prompt()` for taking user input
- `Number()` for converting input into numbers
- `switch` statement for selecting operations
- `if-else` for checking division by zero
- `innerHTML` for displaying the result

## Conclusion
This project helps beginners understand basic JavaScript concepts such as user input, arithmetic operators, conditional statements, and displaying output using HTML.
