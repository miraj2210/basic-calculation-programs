# Even Odd Number Checker Using JavaScript

## Description
This is a simple Even Odd Number Checker created using HTML and JavaScript. It takes a number from the user and checks whether the number is even or odd.

## Features
- Takes a number from the user
- Checks whether the number is even or odd
- Uses an `if-else` statement
- Displays the result on the webpage

## Technologies Used
- HTML
- JavaScript

## How It Works
1. The user enters a number.
2. JavaScript converts the input into a number using `Number()`.
3. The `%` operator checks the remainder when divided by 2.
4. If the remainder is 0, the number is even.
5. Otherwise, the number is odd.
6. The result is displayed on the webpage.

## How to Run
1. Save the code as `index.html`.
2. Open the file in Google Chrome.
3. Enter a number in the prompt box.
4. Click **OK**.
5. View the result on the webpage.

## Example Output

**Input:**
```text
Enter a number: 10
```

**Output:**
```text
The number is Even
```

## JavaScript Concepts Used
- `prompt()` for taking user input
- `Number()` for converting input into a number
- Modulus operator (`%`) for checking even or odd
- `if-else` for checking conditions
- `getElementById()` for selecting an HTML element
- `innerHTML` for displaying the result

## Conclusion
This project helps beginners understand basic JavaScript concepts such as user input, modulus operator, conditional statements, and displaying output on a webpage.
