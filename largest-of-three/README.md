# Largest of Three Numbers Using JavaScript

## Description
This is a simple Largest of Three Numbers program created using HTML and JavaScript. It takes three numbers from the user and finds the largest number.

## Features
- Takes three numbers from the user
- Finds the largest number
- Uses `if-else if-else` statements
- Uses comparison and logical operators
- Displays the result on the webpage

## Technologies Used
- HTML
- JavaScript

## How It Works
1. The user enters the first number.
2. The user enters the second number.
3. The user enters the third number.
4. JavaScript converts the inputs into numbers using `Number()`.
5. The program compares all three numbers using `>=` and `&&` operators.
6. The largest number is displayed on the webpage.

## How to Run
1. Save the code as `index.html`.
2. Open the file in Google Chrome.
3. Enter three numbers in the prompt boxes.
4. Click **OK** after entering each number.
5. View the largest number on the webpage.

## Example Output

**Input:**
```text
Enter first number: 10
Enter second number: 30
Enter third number: 20
```

**Output:**
```text
30 is the largest number
```

## JavaScript Concepts Used
- `prompt()` for taking user input
- `Number()` for converting input into numbers
- Comparison operator (`>=`)
- Logical AND operator (`&&`)
- `if-else if-else` for checking conditions
- `getElementById()` for selecting an HTML element
- `innerHTML` for displaying the result

## Conclusion
This project helps beginners understand basic JavaScript concepts such as user input, comparison operators, logical operators, conditional statements, and displaying output on a webpage.
