# Positive, Negative and Zero Number Checker Using JavaScript

## Description
This is a simple Positive, Negative and Zero Number Checker created using HTML and JavaScript. It takes a number from the user and checks whether the number is positive, negative or zero.

## Features
- Takes a number from the user
- Checks whether the number is positive, negative or zero
- Uses `if-else if-else` statements
- Displays the result on the webpage

## Technologies Used
- HTML
- JavaScript

## How It Works
1. The user enters a number.
2. JavaScript converts the input into a number using `Number()`.
3. If the number is greater than 0, it displays **Positive**.
4. If the number is less than 0, it displays **Negative**.
5. Otherwise, it displays **Zero**.
6. The result is displayed on the webpage.

## How to Run
1. Save the code as `index.html`.
2. Open the file in Google Chrome.
3. Enter a number in the prompt box.
4. Click **OK**.
5. View the result on the webpage.

## Example Output

**Input:**
```text
Enter a number: -10
```

**Output:**
```text
Negative
```

## JavaScript Concepts Used
- `prompt()` for taking user input
- `Number()` for converting input into a number
- Comparison operators (`>`, `<`)
- `if-else if-else` for checking conditions
- `getElementById()` for selecting an HTML element
- `innerHTML` for displaying the result

## Conclusion
This project helps beginners understand basic JavaScript concepts such as user input, comparison operators, conditional statements and displaying output on a webpage.
