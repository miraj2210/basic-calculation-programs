# Simple Arithmetic Calculator Using JavaScript

## Description
This is a simple arithmetic calculator created using HTML and JavaScript. It takes two numbers from the user and performs basic arithmetic operations.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Displays results in the browser console

## Technologies Used
- HTML
- JavaScript

## How It Works
1. The user enters the first number.
2. The user enters the second number.
3. JavaScript performs four arithmetic operations.
4. An `if-else` statement checks for division by zero.
5. The results are displayed in the browser console.

## How to Run
1. Save the code as `index.html`.
2. Open the file in Google Chrome.
3. Enter two numbers in the prompt boxes.
4. Press `F12` and open the **Console** tab.
5. View the results.

## Example Output

**Input:**
```text
Enter first number: 10
Enter second number: 5
```

**Console Output:**
```text
15
Difference = 5
Product = 50
Division = 2
```

## JavaScript Concepts Used
- `prompt()` for taking user input
- `Number()` for converting input into numbers
- Arithmetic operators (`+`, `-`, `*`, `/`)
- `if-else` for checking division by zero
- `console.log()` for displaying results

## Conclusion
This project helps beginners understand basic JavaScript arithmetic operations, user input, conditional statements, and console output.
