# Area of Circle Using JavaScript

## Description
This is a simple Area of Circle program created using HTML and JavaScript. It takes the radius from the user and calculates the area of a circle.

## Features
- Takes the radius from the user
- Calculates the area of a circle
- Uses a simple mathematical formula
- Displays the result on the webpage

## Technologies Used
- HTML
- JavaScript

## How It Works
1. The user enters the radius of a circle.
2. JavaScript converts the input into a number using `Number()`.
3. The program calculates the area using the formula `3.14 * r * r`.
4. The calculated area is displayed on the webpage.

## How to Run
1. Save the code as `index.html`.
2. Open the file in Google Chrome.
3. Enter the radius in the prompt box.
4. Click **OK**.
5. View the area of the circle on the webpage.

## Example Output

**Input:**
```text
Enter radius: 5
```

**Output:**
```text
Area of Circle = 78.5
```

## JavaScript Concepts Used
- `prompt()` for taking user input
- `Number()` for converting input into a number
- Variables using `let`
- Multiplication operator (`*`)
- `getElementById()` for selecting an HTML element
- `innerHTML` for displaying the result

## Conclusion
This project helps beginners understand basic JavaScript concepts such as user input, variables, arithmetic operations, mathematical calculations, and displaying output on a webpage.
