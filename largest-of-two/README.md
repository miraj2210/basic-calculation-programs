# Largest of Two Numbers Using JavaScript

## Description
This is a simple Largest of Two Numbers program created using HTML and JavaScript. It takes two numbers from the user and checks which number is larger.

## Features
- Takes two numbers from the user
- Finds the largest number
- Checks if both numbers are equal
- Uses `if-else if-else` statements
- Displays the result on the webpage

## Technologies Used
- HTML
- JavaScript

## How It Works
1. The user enters the first number.
2. The user enters the second number.
3. JavaScript converts both inputs into numbers using `Number()`.
4. If the first number is greater, it displays the first number as the largest.
5. If the second number is greater, it displays the second number as the largest.
6. Otherwise, it displays that both numbers are equal.

## How to Run
1. Save the code as `index.html`.
2. Open the file in Google Chrome.
3. Enter the first number in the prompt box.
4. Enter the second number in the prompt box.
5. Click **OK**.
6. View the result on the webpage.

## Example Output

**Input:**
```text
Enter first number: 20
Enter second number: 10
```

**Output:**
```text
20 is the largest number
```

## JavaScript Concepts Used
- `prompt()` for taking user input
- `Number()` for converting input into numbers
- Comparison operators (`>`)
- `if-else if-else` for checking conditions
- `getElementById()` for selecting an HTML element
- `innerHTML` for displaying the result

## Conclusion
This project helps beginners understand basic JavaScript concepts such as user input, comparison operators, conditional statements, and displaying output on a webpage.
